Touche pour continuer

Sur le 8,
la version minimale,
complète.

Touche comme dans l'app. Les boutons, les onglets et les lignes mènent à l'écran suivant.

Touche ailleurs : les zones actives s'allument en bleu.

Appui long n'importe où : le menu (écran précédent, recommencer, côté prof ou élève, aller à un écran).

Le tour complet passe de Mike, le prof, à Alexis, l'élève, et revient, comme dans la vraie boucle.

Pour le plein écran sur iPhone : Partager → « Sur l'écran d'accueil », puis ouvre « Sur le 8 » depuis l'icône.
